# Fast Notes

**Fast Notes** is a lightweight desktop notes application by [Raycynix](https://github.com/raycynix), designed for quickly capturing ideas, tasks, snippets and anything you don't want to lose.

> This repository is the **public release and update channel** for Fast Notes.  
> The application source code is maintained separately.

## Downloads

The latest version of Fast Notes is available on the [Releases](../../releases/latest) page.

### Windows

Release assets may include:

- **`.exe`** — NSIS installer
- **`.msi`** — Windows Installer package
- **`.sig`** — signed update artifacts
- **`latest.json`** — update manifest used by the application

For most users, the `.exe` installer is the recommended option.

## Automatic updates

Fast Notes uses this repository as its public update endpoint.

When a new version is released, the application can check the published `latest.json` manifest, download the appropriate signed package and install the update.

Release artifacts are generated from the private Fast Notes source repository and published here automatically.

## Release integrity

Update packages are signed before publication. Fast Notes verifies updater signatures before installing an update.

Files published outside the official Raycynix release channels should not be considered official Fast Notes builds.

## About Fast Notes

Fast Notes is focused on making note-taking immediate and unobtrusive:

- quick note capture;
- desktop-first workflow;
- tray access;
- favorites, tags and organization;
- Markdown-based editing;
- lightweight interface designed to stay out of the way.
